# GTA 6 HQ press kit

Everything needed to write about, review or film GTA 6 HQ. You do not need to ask first.

## What it is

**In one line:** GTA 6 HQ is a free, unofficial Grand Theft Auto VI encyclopedia, map and field manual for Windows, Mac and Linux.

**In a paragraph:** GTA 6 HQ gathers what is known about Grand Theft Auto VI into one desktop app: an encyclopedia of characters, locations and vehicles, a map of Leonida, a media gallery, and a Field Manual laid out like a printed game manual. Every fact is labelled by how well it is supported, from official material to interpretation, and links to its source. It is made by fans, it is free, and it has no ads, accounts or tracking. The Windows version is the finished one; the Mac and Linux versions are previews.

## If you cover it

- Call it **unofficial** or **fan-made**. It is not a Rockstar product.
- Link the download or this repository so people get the real file.
- The app's own pages, text and code are free to show. The game artwork, screenshots and footage inside it belong to Rockstar Games and Take-Two Interactive, as they would in any GTA video.
- Tell us in the Discord server or in [Discussions](https://github.com/xpbeats00-sudo/gta6-hq/discussions) and we will share it.
